03 Method

모든 수업은 세 단계로 흐릅니다

개념을 알아도 틀리고, 유형을 외워도 틀립니다. 그래서 마지막 단계는 언제나 ‘왜 틀렸는가’입니다.

  1. 01√
    CONCEPT

    개념

    공식을 외우기 전에 왜 그 공식이 나오는지 직접 유도합니다. 수업 끝 10분, 배운 개념을 학생이 칠판에서 설명합니다.

    비중
    수업 시간의 35%
    확인
    구술 테스트 · 개념 노트
  2. 02∫
    PATTERN

    유형

    기출을 유형별로 묶어, 처음 보는 문제에서도 출발점을 찾도록 훈련합니다. 문제 수보다 풀이 경로의 수를 늘립니다.

    비중
    수업 시간의 45%
    확인
    주간 테스트 · 풀이 시간 기록
  3. 03∞
    ERROR CLINIC

    오답 클리닉

    틀린 문제를 ‘계산·개념·해석·시간’ 네 가지 원인으로 분류하고, 같은 원인의 문제를 다시 풀 때까지 클리닉 조교가 붙습니다.

    비중
    수업 외 주 1회 90분
    확인
    오답 원인 리포트 · 재시험

수업이 끝나도 남는 것

한 학기 동안 쌓인 오답 노트 한 권이, 성적표보다 먼저 아이의 약점을 알려줍니다.
